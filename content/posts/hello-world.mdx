## Welcome

This is the first post on my new blog. I built this site with [Next.js](https://nextjs.org) and MDX to have a fast, simple place to write.

MDX lets me mix Markdown with React components. Here's what that looks like:

### Code blocks with syntax highlighting

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`
}

console.log(greet('World'))
```

### Rich content

- **Bold text** and _italics_ work as expected
- Links to [external sites](https://example.com) open in new tabs
- Images are optimized with `next/image`

> Blockquotes look great for callouts and asides.
