Next.js is a React framework that gives you building blocks to create web applications. Here's how to get started.

## Create a new project

```bash
npx create-next-app@latest my-app --typescript --tailwind
```

This scaffolds a project with:

- **TypeScript** for type safety
- **Tailwind CSS** for styling
- **App Router** for file-based routing
- **ESLint** for code quality

## Project structure

```
my-app/
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
├── components/
├── lib/
└── public/
```

## Your first page

Create `app/about/page.tsx`:

```tsx
export default function About() {
  return (
    <div>
      <h1 className="text-2xl font-bold">About</h1>
      <p>This is the about page.</p>
    </div>
  )
}
```

Visit `/about` in your browser — the page is live without any route configuration.

## Server Components by default

In the App Router, components are **Server Components** by default. This means they run on the server and send only HTML to the client. For interactivity, add `'use client'` at the top of the file.

```tsx
'use client'

import { useState } from 'react'

export function Counter() {
  const [count, setCount] = useState(0)
  return (
    <button onClick={() => setCount(count + 1)}>
      Count: {count}
    </button>
  )
}
```

## Building for production

```bash
npm run build
npm start
```

Next.js generates static HTML for every page at build time. The result is a fast, SEO-friendly site that can be deployed anywhere.
